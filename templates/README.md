# Templates

Light, day-one starting points. The setup prompt scaffolds your repo using the
same shapes; these are here as reference and for copying by hand.

| File | Use |
|------|-----|
| `note.md` | A knowledge-base page. Light 4-field frontmatter. |
| `project-overview.md` | A project's `project-overview.md`. Overview / Current state / Next. |
| `universe.md` | The living map of your world, seeded at setup and kept alive. |
| `CLAUDE-lite.md` | Five rules and a failure log to paste into any project. No dependencies. |
| `failure-log.md` | The failure-log starter. The one primitive worth keeping if you keep nothing else. |
| `CLAUDE.md.template` | A fuller CLAUDE.md starter. |

## Frontmatter is light on purpose

Day-one frontmatter is four fields only:

```yaml
---
title:
status:
tags: []
updated:
---
```

A fuller schema (owner, last_reviewed, review_every, sources) is a graduation
step, not a day-one cost. See [ROADMAP.md](../ROADMAP.md).
