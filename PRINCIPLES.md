# Principles

Discipline beats tooling.

The degradation is between components, not within them.

Constraints scale better than capabilities.

Every repeated failure is a governance bug.

Live state wins.

Coordination load compounds silently.

Explicit contracts beat ambient context.

Failure logs are operational memory.

Quiet wrongness is more dangerous than obvious failure.

The system should learn from its own failures.

Capability expands surface area. Discipline reduces it.

Coherence is maintained, not assumed.
