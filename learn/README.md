# Nexus: Core Concepts Primer

A short set of learning modules for new operators. The aim is to orient you, show you the arc of where this goes, and point you at the real setup materials. This is not the setup itself, it is the map you read before you start.

Each module takes a few minutes. Read them in order if this is new to you, or jump to whatever you need.

## Start here

If you only do one thing, read [Your First Hour](./00-your-first-hour.md). It describes the five small things you set up on day one, and the one command you actually run.

## Day one is small

A recurring theme runs through all of this: day one is deliberately tiny. You start with a goal, a living map, a knowledge base, a failure log, and one command. Everything else in the arc is a destination, pulled in later by real need, not a checklist you complete up front.
